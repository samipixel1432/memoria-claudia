# memoria-claudia

Memoria permanente de Claude para el trabajo en Tovelya. Claude la lee al empezar cada conversación y la actualiza al terminar, en el computador o en la nube.

- `CLAUDE.md`: las reglas que sigue Claude para leer y guardar memoria.
- `memory/`: una nota por cada hecho, con el índice en `memory/MEMORY.md`.
- `contexto/ESTADO-TOVELYA.md`: el estado actual de la tienda, las campañas, las landings y los pendientes.

Para usarla en un chat nuevo, pídele a Claude: "lee mi memoria en github.com/samipixel1432/memoria-claudia".
